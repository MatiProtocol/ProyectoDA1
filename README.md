# TaskTrackPro

## Obligatorio

Obligatorio para la materia Diseño 1 con el fin de utilizar las tecnologias .NET, C#, MSTest, Blazor y persistencia de datos con bases de datos. Se utilizará la metodología de TDD sobre el dominio del proyecto.

## Compilación 

Se utilizará JetBrains Rider para la compilación y/o ejecución del proyecto.
Otra opción de compilación es:
```terminal
 $ dotnet build
```

## Testing

Se utilizará JetBrains Rider para correr los tests del dominio del proyecto.
Otra opción es:
```terminal
 $ dotnet test Tests
```
